# 🌐 Panduan Membuat Aplikasi Online 24/7 & Download File APK

Dokumen ini berisi panduan langkah demi langkah agar aplikasi **AI Facial Health Screening** dapat:
1. **Aktif 24 jam nonstop di internet** (tanpa perlu menyalakan laptop Anda sama sekali).
2. **Bisa di-download dan dipasang di HP (Android/iOS) maupun Laptop**.
3. **Bisa di-generate menjadi file mentah `.apk`** yang dapat dikirim lewat WhatsApp.

---

## 🚀 BAGIAN 1: Mengaktifkan Aplikasi Online 24/7 (100% GRATIS)

Layanan resmi **Streamlit Community Cloud** menyediakan server hosting gratis selamanya dengan sertifikat keamanan **HTTPS** resmi.

### Langkah 1: Buat Repository di GitHub
1. Buka [github.com](https://github.com) dan login ke akun Anda (buat akun gratis jika belum punya).
2. Klik tombol **"+"** di pojok kanan atas $\rightarrow$ pilih **"New repository"**.
3. Beri nama repository, misalnya: `skrining-kesehatan-wajah`.
4. Pilih **Public** $\rightarrow$ biarkan kotak lain kosong $\rightarrow$ klik **"Create repository"**.
5. Salin link repository Anda (contoh: `https://github.com/username/skrining-kesehatan-wajah.git`).

### Langkah 2: Unggah Proyek dari Laptop
1. Buka folder `D:\facial_health_screening`.
2. Klik ganda file: **`upload_ke_github.bat`**.
3. Tempelkan (*paste*) link repository GitHub Anda tadi, lalu tekan **Enter**.
4. Semua file proyek akan otomatis terunggah ke GitHub Anda dalam beberapa detik.

### Langkah 3: Deploy di Streamlit Cloud
1. Buka [share.streamlit.io](https://share.streamlit.io) dan login dengan akun GitHub Anda.
2. Klik tombol **"Create app"** (atau "New app").
3. Pilih repository yang baru saja Anda buat: `skrining-kesehatan-wajah`.
4. Kolom **Main file path** pastikan terisi: `app.py`.
5. Klik **"Deploy!"**.

> ⏳ **Tunggu 1–2 menit.** Server cloud akan otomatis menginstal seluruh pustaka AI.  
> Begitu selesai, Anda akan mendapatkan alamat URL resmi permanen, misalnya:  
> 👉 **`https://skrining-kesehatan-wajah.streamlit.app`**
> 
> **Mulai saat ini, Anda bisa mematikan laptop Anda, dan aplikasi akan tetap aktif online 24 jam nonstop dari mana saja di seluruh dunia!**

## 📲 BAGIAN 2: Cara Download & Pasang Aplikasi di HP (PWA)

Setelah aplikasi Anda memiliki link web resmi di atas:

### Di HP Android:
1. Buka link web tersebut menggunakan **Google Chrome** di HP Anda.
2. Ketuk ikon **Titik 3** di pojok kanan atas Chrome.
3. Pilih menu: **"Install Aplikasi"** (atau *"Tambahkan ke Layar Utama"*).
4. Selesai! Ikon aplikasi **TriageWajah** dengan logo dokter medis akan muncul di layar menu HP Anda seperti aplikasi Play Store.

### Di iPhone (iOS):
1. Buka link web tersebut menggunakan browser **Safari**.
2. Ketuk tombol **Bagikan / Share** (ikon kotak dengan panah ke atas di bagian bawah).
3. Gulir ke bawah dan pilih **"Add to Home Screen"** (*Tambahkan ke Layar Utama*).
4. Ikon aplikasi akan muncul di beranda iPhone Anda dan terbuka dalam layar penuh (*fullscreen*).

### Di Laptop / PC (Desktop Windows / Mac):
1. Buka link web tersebut di Google Chrome atau Microsoft Edge.
2. Perhatikan ujung kanan bilah alamat (URL bar) di atas, akan muncul ikon komputer dengan panah bawah (*"Install app"*).
3. Klik ikon tersebut $\rightarrow$ aplikasi akan terpasang di Desktop & Start Menu komputer Anda.

## 📦 BAGIAN 3: Cara Mengunduh File Mentah `.APK` (Android Package)

Jika Anda ingin memiliki file berformat **`nama_file.apk`** yang bisa disimpan di flashdisk atau dibagikan lewat chat WhatsApp:

1. Pastikan aplikasi Anda sudah online (sudah memiliki link web dari Bagian 1 di atas).
2. Buka situs resmi buatan Microsoft: **[pwabuilder.com](https://www.pwabuilder.com/)**.
3. Masukkan link web aplikasi Anda (misal `https://skrining-kesehatan-wajah.streamlit.app`) lalu klik tombol **"Start"**.
4. PWA Builder akan memeriksa manifest yang sudah kita buat (skornya akan hijau 100%).
5. Klik tombol **"Package for Android"** (atau *Generate APK*).
6. Klik **"Download APK"**.
7. Anda akan langsung mendapatkan file **`.apk`** mentah yang siap di-install di HP Android mana saja!
